# Kyoto · Osaka 旅程手帳

目前是本機預覽版，使用純 HTML、CSS、JavaScript 製作，不需要安裝框架或套件。

## 開啟方式

直接用瀏覽器開啟 `index.html` 即可。

若希望使用本機伺服器，也可以在此資料夾執行：

```text
python -m http.server 5500
```

再用瀏覽器開啟 <http://localhost:5500>。

## 檔案說明

- `index.html`：網站結構與文字區塊
- `styles.css`：響應式版面與視覺風格
- `app.js`：每日行程資料、交通推薦、景點細節、餐廳與 Google Maps 連結
- `trip-planning.md`：下載資料、交通討論結論、住宿、餐廳與後續待確認事項

## 目前版本功能

- 以 Excel 為主版本：Day 4 嵐山、Day 5 天橋立
- Day 5 採自行前往版本：View Land＋觀光船＋傘松公園
- 每個行程節點都有「查看細節」按鈕，顯示交通、營業時間參考與官方連結
- 住宿地址與地圖入口
- Excel 中的餐廳備選
- 待確認清單可新增、刪除、勾選，並保存在目前瀏覽器的 localStorage

## 待確認內容

景點營業時間、JR／觀光船／纜車班次會依季節、天候與官方公告變動；網站中的時間是目前整理的常態參考，出發前需要重新確認。


## 新增功能
主要更新與修改記錄 (2026-10)
雲端即時同步功能 (JSONBin.io)：

整合 JSONBin.io 雲端同步機制。
「想吃清單」、「TO CHECK (待確認清單)」以及新增的「已訂位」項目皆可自動即時同步，所有旅伴皆能透過多裝置查看最新進度。

每日行程下方新增「已訂位」管理欄位：

於每個 Day 的餐廳區塊下方新增「已訂位」專屬區塊。
支援輸入訂位時間、餐廳名稱與選填的訂位連結，並可隨時點擊刪除已建立的訂位紀錄。
優化排版，改為兩行式彈性配置，解決時間欄位在行動端或較窄畫面上被擠壓或切到的問題。

介面內容優化：

精簡各頁面說明文字，移除冗長或突兀的行文。
確保地圖、Tabelog 搜尋與各日官方資訊指引清晰易用。
