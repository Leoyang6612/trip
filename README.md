# Kyoto · Osaka 旅程手帳

目前是本機預覽版，使用純 HTML、CSS、JavaScript 製作，不需要安裝框架或套件。

## 開啟方式

直接用瀏覽器開啟 `index.html` 即可。

若希望使用本機伺服器，也可以在此資料夾執行：

```text
python -m http.server 5500
```

再用瀏覽器開啟 <http://localhost:5500>。

## 檔案說明

- `index.html`：網站結構與文字區塊
- `styles.css`：響應式版面與視覺風格
- `app.js`：每日行程資料、交通推薦、景點細節、餐廳與 Google Maps 連結
- `trip-planning.md`：下載資料、交通討論結論、住宿、餐廳與後續待確認事項

## 目前版本功能

- 以 Excel 為主版本：Day 4 嵐山、Day 5 天橋立
- Day 5 預計跟團（待確認）；網站保留 View Land＋觀光船＋傘松公園自助版作備案
- 每個行程節點都有「查看細節」按鈕，顯示交通、營業時間參考與官方連結
- 住宿地址與地圖入口
- Excel 中的餐廳備選
- 待確認清單、想吃清單與每日餐廳清單透過 JSONBin.io 同步，旅伴可跨裝置查看與更新

## 待確認內容

景點營業時間、JR／觀光船／纜車班次會依季節、天候與官方公告變動；網站中的時間是目前整理的常態參考，出發前需要重新確認。


## 新增功能
主要更新與修改記錄 (2026-10)
雲端即時同步功能 (JSONBin.io)：

整合 JSONBin.io 雲端同步機制。
Checklist、想吃 Tag 與每日餐廳（含備註、連結及訂位狀態）透過 JSONBin.io 即時同步，旅伴可跨裝置查看與更新。

每日行程餐廳清單管理：

每間餐廳統一記錄名稱、備註與單一連結，可新增或刪除；雙擊備註文字即可編輯。
餐廳卡片右上方的狀態按鈕可切換「備選」與「已訂位」；舊訂位資料轉成備選，使用者可重新標記。
新增表單預設收起，點擊「今天吃什麼」標題旁的＋才展開。

介面內容優化：

精簡各頁面說明文字，移除冗長或突兀的行文。
「隨身入口」保留 Tabelog 與日本氣象廳；交通路線圖依當日行程顯示在「今天先開這些」。
